# Sky Saver

本物の空の動きを描く Mac のスクリーンセーバーです（無料・アルファ版）。
Sky Saver is a Mac screen saver that paints a living sky. Free, alpha.

製品ページ / Website: https://www.ultrawarp.jp/skysaver/ ・ [English](https://www.ultrawarp.jp/skysaver/en/)

## ダウンロード / Download

**ダウンロードページ / Download page: https://satoo3.github.io/SkySaver-releases/**

[最新のリリース / Latest release](https://github.com/satoo3/SkySaver-releases/releases/latest) から `SkySaver-<version>-mac.dmg` をダウンロードして開き、
SkySaver を「アプリケーション」フォルダへドラッグしてから開いてください。スクリーンセーバーを入れるかを聞かれたら「入れる」を押し、
システム設定のスクリーンセーバーで Sky Saver を選びます。

Download `SkySaver-<version>-mac.dmg` from the [latest release](https://github.com/satoo3/SkySaver-releases/releases/latest), open it,
drag SkySaver to the Applications folder and open it from there. Click 入れる (Install) when it asks to install the screen saver,
then choose Sky Saver in System Settings → Screen Saver.

- macOS 12 Monterey 以降（Apple シリコン・Intel）/ macOS 12 or later (Apple silicon and Intel)
- Apple の公証済み / Notarized by Apple
- アプリの表示は日本語だけです / The app is in Japanese only for now
