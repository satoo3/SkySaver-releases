# Sky Saver

A Mac screen saver that paints a living sky: the sun, moon and stars where they really are over the place you choose,
clouds that drift and change, weather, and the sea under it. Free, alpha.

Website: https://www.ultrawarp.jp/skysaver/en/

## Download

**Download page: https://satoo3.github.io/SkySaver-releases/**

1. Download `SkySaver-<version>-mac.dmg` from the [latest release](https://github.com/satoo3/SkySaver-releases/releases/latest) and open it.
2. Drag SkySaver to the Applications folder, then open it from there.
3. Click **Install** when it asks to install the screen saver.
4. Choose Sky Saver in System Settings → Screen Saver.

- macOS 12 Monterey or later (Apple silicon and Intel)
- Signed with Developer ID and notarized by Apple
- The settings app is in English and Japanese (it follows your Mac's language)
